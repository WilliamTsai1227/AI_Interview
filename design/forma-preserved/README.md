## 只調整的風格

- 米白 Paper `#F4F3ED`、暖灰側欄 `#ECEBE4`、Ink `#24251F`。
- 朱紅 `#BD442E` 用於選取狀態、圖示、題號、分數和細節；主要按鈕維持黑色膠囊。
- 各頁最大標題沿用正式前端的無襯線字體、字重、字級、字距與行高，包含「準備好就開始」；操作與內文使用 DM Sans / Noto Sans TC。
- 用細線、較節制的圓角與局部間距調整元件質感，保留原有的區塊順序與版型。
- 沒有加入首頁幾何海報、巨型品牌標題、頂部功能導覽或工具目錄等新資訊架構。

## 原型邊界

`demo.js` 在此預覽分頁提供記憶體中的假資料，讓原本頁面程式正常顯示與操作。搜尋、選擇職缺／履歷、面試設定、題庫編輯與示範出題、準備清單、報告和履歷設定卡片可供查看。題庫編輯重新整理後重置。

開始面試、上傳、真實 AI 分析與其他未提供假資料的操作會明確提示預覽限制，不啟動錄音或假裝完成。無登入、無正式資料存取、無資料庫；瀏覽器字型載入是唯一外部資源需求。

`editorial.css` 是未來實作的樣式提案；本次 **沒有修改任何 `frontend/`、後端或部署設定**。
