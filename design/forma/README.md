# forma. / Editorial Minimalism

這是 AI Interview 的第二條獨立設計方向，位於 `feat/forma-editorial-design`。保留 AI 面試與職涯準備定位，將品牌重新命名為 **forma.**。舊版 `.fig` 與預覽圖保留供比較，正式 `frontend/` 與後端沒有變動。

## 預覽

從專案根目錄執行：

```sh
python3 -m http.server 8010 --bind 127.0.0.1 --directory design/forma
```

開啟 <http://127.0.0.1:8010/>。無須安裝套件、註冊或設定 API。也可直接以瀏覽器開啟 `index.html`。Google Fonts 需要網路；無網路時使用系統字體。

## 設計決策

- **配色**：Paper `#F4F3ED`、Ink `#24251F`、Olive `#77796E`、Vermilion `#BD442E`。分隔線 `#CDCDC3`，幾何底色 `#EAEAE2`。小字採用較深的 `#66685E`（紙白背景對比約 5.10:1），保留 Olive 原色供幾何與品牌色票使用。
- **字體**：Georgia 品牌與英文編輯字體、Noto Serif TC 的教練觀察與提問、DM Sans / Noto Sans TC 操作與標題。巨型標題與正文分層，英文不取代中文操作標籤。
- **構圖**：桌面主區為 1.65 : 1 的非對稱雙欄。頂部導覽、細線結構、直角按鈕；不用陰影、膠囊卡片或深色舞台。
- **品牌圖形**：以 CSS 原生半圓和斜軸構成「尚在整理、持續前進」的意象，無外部圖片依賴。
- **產品內容**：沿用職缺、Ava、面試、履歷、能力落差與準備路線。總覽的數字以準備度為中心，主要行動只有開始練習。
- **對照簡報**：`#identity` 為色彩、字體與幾何語言的視覺規範頁。

## 可以操作的範圍

| 頁面                 | 可操作內容                                           |
| -------------------- | ---------------------------------------------------- |
| 總覽 `#overview`     | 三個目標職缺切換，準備度、弱項、Ava 觀察同步變化     |

工具提供「均衡 / 深入」兩種示範思考方式，模擬產生不同內容。輸入與輸出使用 DOM API / `textContent`，不插入使用者 HTML。

## 資料與限制

全部職缺、分數、回饋與生成內容為示範資料，**未串接正式 AI API、登入、錄音或持久化資料庫**。模擬面試不提供假造的 AI 評分，完成後顯示未評分摘要。Google Fonts 為唯一外部資源請求。

新增紀錄與職缺選擇使用 `sessionStorage`，重新整理後保留、關閉分頁後清除。練習中途離開則捨棄未完成回答。正式站台與帳號資料不受影響。

## 驗收重點

- 桌面、平板及 375 px 行動版不應出現橫向溢出。
- Tab 焦點可見，dialog 支援 Escape 與瀏覽器原生焦點限制，手機導覽提供 `aria-expanded`。
- 搜尋空結果、少於 10 字的輸入、完成練習與離開狀態均有明確回饋。
- 關閉產生中的工具會取消模擬工作；不應在關閉後新增紀錄。
- 使用減少動態效果設定時關閉過場效果。

## 本次驗證

JavaScript 語法與 HTML 解析通過；以 Happy DOM 在暫存環境執行 20 項互動檢查，涵蓋職缺切換、工具分類與搜尋、輸入驗證、示範生成、關閉取消、三題面試、紀錄詳情與行動版選單狀態。預覽 HTTP 回應為 200。
