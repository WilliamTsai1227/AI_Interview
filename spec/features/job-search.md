# 職缺搜尋（第一版關閉）

## 狀態

第一版**關閉**（`FEATURE_JOB_SEARCH=false`）。程式碼保留，改成 `true` 並重啟 `api` 就會打開。

## 為什麼做

讓還沒有明確目標的使用者，從平台的職缺庫挑一個職缺開始練習。

## 為什麼先關掉

平台職缺需要穩定、合法、品質好的資料來源。之前的爬蟲效果不好，平台職缺已經清空。在有可靠的資料來源之前，使用者自己貼上職缺比較準。

## 打開前要先確認

- 有穩定的職缺資料來源（公司官網結構化資料、合作授權等），而且資料夠新、夠完整。
- 職缺會定期檢查是否還在招募。

## 怎麼測試

- 開關關閉：側邊欄、「新增目標職缺」選單、新面試頁、全站搜尋都看不到職缺搜尋；直接輸入 `#jobs` 會導回新面試；`GET /api/v1/jobs` 回 404。
- 開關打開：上述入口都出現，搜尋有結果，可以把職缺加成目標職缺。
- 不論開關，職缺詳情（`GET /api/v1/jobs/{id}`）都要能正常打開。
