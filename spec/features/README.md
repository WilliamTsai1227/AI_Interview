# 產品功能說明

每個功能一份文件，寫三件事：**為什麼做**（站在使用者角度）、**怎麼用**、**怎麼測試效果**。

產品核心：**針對一個想應徵的職缺，反覆做語音模擬面試，拿到具體回饋，直到準備好。**

導覽以職缺為中心：側欄是「新面試」、「職缺」（直接列出使用者的職缺，依最近練習排序，最多 6 個，其餘在「全部職缺」）、「面試報告」、「履歷修改」、「能力落差分析」。
點一個職缺進入職缺頁，分頁是「總覽／題庫／面試建議／報告」（網址 `#targets/{id}`、`#questions/{id}`、`#prep/{id}`、`#targets/{id}/reports`）。

| 功能 | 一句話 | 文件 |
|---|---|---|
| 我的職缺（原目標職缺） | 把想應徵的職缺貼進來，所有練習都圍繞它；職缺頁的「總覽」分頁 | [target-jobs.md](target-jobs.md) |
| 題庫 | 針對這個職缺的題目，可以自己增刪改；職缺頁的「題庫」分頁 | [question-bank.md](question-bank.md) |
| 面試建議 | 面試前先知道會被問什麼、要準備什麼；職缺頁的「面試建議」分頁 | [prep.md](prep.md) |
| 語音模擬面試 | 跟 AI 面試官用講的練習，會追問 | [mock-interview.md](mock-interview.md) |
| 面試報告 | 每題打分、告訴你怎麼講更好 | [report.md](report.md) |
| 履歷修改 | 用一關一關的卡片問出履歷沒寫的經歷，依職缺產生新版履歷 | [resume-revision.md](resume-revision.md) |
| 能力落差分析（原求職準備、職涯規劃） | 選一份履歷和 1–5 個想應徵的職缺，看還差什麼、怎麼補 | [career-plan.md](career-plan.md) |
| 履歷與設定 | 上傳履歷、設定預設的面試方式 | [resume-settings.md](resume-settings.md) |
| 帳號與登入 | Email 或 Google 登入 | [account.md](account.md) |
| 連接 Notion（MCP 連接器） | 授權 Notion，讓 AI 匯出報告、讀取準備筆記 | [mcp-connectors.md](mcp-connectors.md) |
| 職缺搜尋（第一版關閉） | 從平台職缺庫挑職缺 | [job-search.md](job-search.md) |
