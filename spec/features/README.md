# 產品功能說明

每個功能一份文件，寫三件事：**為什麼做**（站在使用者角度）、**怎麼用**、**怎麼測試效果**。

產品核心：**針對一個想應徵的職缺，反覆做語音模擬面試，拿到具體回饋，直到準備好。**

| 功能 | 一句話 | 文件 |
|---|---|---|
| 目標職缺 | 把想應徵的職缺貼進來，所有練習都圍繞它 | [target-jobs.md](target-jobs.md) |
| 面試題庫 | 針對這個職缺的題目，可以自己增刪改 | [question-bank.md](question-bank.md) |
| 面試建議 | 面試前先知道會被問什麼、要準備什麼 | [prep.md](prep.md) |
| 語音模擬面試 | 跟 AI 面試官用講的練習，會追問 | [mock-interview.md](mock-interview.md) |
| 面試報告 | 每題打分、告訴你怎麼講更好 | [report.md](report.md) |
| 職涯規劃 | 看自己離目標職缺還差什麼、怎麼補 | [career-plan.md](career-plan.md) |
| 履歷與設定 | 上傳履歷、設定預設的面試方式 | [resume-settings.md](resume-settings.md) |
| 帳號與登入 | Email 或 Google 登入 | [account.md](account.md) |
| 職缺搜尋（第一版關閉） | 從平台職缺庫挑職缺 | [job-search.md](job-search.md) |
