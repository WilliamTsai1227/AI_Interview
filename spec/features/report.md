# 面試報告

## 為什麼做

練完之後，使用者最需要知道：「**我哪裡講得不好？怎麼講會更好？下次該練什麼？**」

只有分數沒有用，要有具體、能照著改的建議，練習才會進步。

## 怎麼用

面試結束後自動產生（每題回答完就在背景開始評分，所以結束後很快就有）：

- 總分、五個面向：內容結構、專業深度、表達流暢、職缺契合、自信程度。
- 下次練習的重點。
- 逐題回顧：你的回答（逐字稿）、分數、哪裡好、哪裡要改、「**可以這樣說**」（示範更好的講法）。
- 弱項一鍵加入題庫，下次優先練。
- 評分失敗的題目可以「重新評分」。

## 怎麼測試

**功能**
- 面試結束後 1 分鐘內出現完整報告；每題都有逐字稿和分數。
- 弱項加入題庫 → 題庫最前面出現這些題目。
- 沒有回答任何題目就結束 → 不產生報告，畫面有說明。

**效果**
- **評分一致性**：同一段回答評兩次，分數差距應該在幾分之內。
- **分數合理**：刻意講一個很爛的回答（離題、很短）和一個好回答，分數要明顯拉開。
- **「可以這樣說」**：要是口語、能直接講出來的內容，而且是根據使用者原本的經驗改寫，不是換成一個不存在的故事。
- 逐字稿要準確（評分以面試後的準確版轉錄為準）。
