# 面試題庫

## 為什麼做

使用者常常知道「這家一定會問某件事」，或想多練自己弱的類型。AI 出的題目不一定剛好是他要的，所以題庫要能**自己掌控**：加題、改題、刪題、排順序、決定要不要追問。

模擬面試會照題庫的順序提問。

## 怎麼用

- 在題庫頁輸入需求（例如「多問帶人和 Code Review」），選類別、難度、題數，按「生成題目」。重複的題目會自動略過。
- 每題可以編輯文字、類別、難度，上下移動調整順序，刪除。
- 自己新增題目。
- 每題設定追問方式：不追問、固定追問幾次、預設好的追問題、Ava 自己判斷（最多幾次）。
- 面試報告裡的弱項可以一鍵加回題庫（放在最前面）。

## 怎麼測試

**功能**
- 生成 5 題 → 題數正確、沒有跟現有題目重複。
- 編輯、刪除、排序後重新整理頁面，結果有保留；模擬面試的出題順序跟題庫一致。
- 設成「不追問」的題目，面試時真的不會追問；「固定 2 次」就追問 2 次。

**效果**
- 題目的類別和難度符合選擇；「進階」題應該問到取捨和細節，不是定義題。
- 輸入的需求有被反映在新題目裡。
