# 面試建議

## 為什麼做

練習之前，使用者最想知道：「**這個職缺會問我什麼？我哪裡會被挑戰？面試前要準備什麼？**」

面試建議把職缺和履歷對照，直接給出答案，讓練習有方向。

## 怎麼用

加入目標職缺後會自動分析（有履歷會比對履歷）。頁面包含：

- 職缺契合度。
- 你的優勢、需要補強的地方。
- 高機率會問的方向、可能被問的題目（可以加進題庫）。
- 面試前準備清單（可以打勾）。
- 「再多產生」更多題目或清單；換履歷或職缺內容更新後，按「重新分析」。重新分析只新增、不刪除。

## 怎麼測試

**功能**
- 加入目標職缺後，幾十秒內出現完整內容。
- 可能被問的題目加進題庫 → 題庫頁看得到。
- 準備清單打勾後重新整理還在。
- 換履歷 → 自動重新分析。

**效果**
- 優勢和補強點要有根據：每一點都能在履歷或職缺裡找到依據，不能編造使用者沒有的經歷。
- 沒有履歷時，不應該說出「你的某某經驗」這種內容。
- 可能被問的題目要具體到這個職缺，不是「請自我介紹」這種每家都有的題目佔大多數。
