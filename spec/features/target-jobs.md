# 目標職缺

## 為什麼做

使用者不是想「練面試」，是想「通過**這一家**的面試」。每家公司、每個職缺要的東西不一樣，通用題目練再多也不一定有用。

所以一切從目標職缺開始：題庫、面試建議、模擬面試、報告，都是針對這個職缺產生的。

## 怎麼用

1. 「新增目標職缺」→ 把職缺內容整段貼上（從 104、CakeResume、公司官網複製都可以）。網址選填。
2. Ava 會整理出公司、職稱、工作內容、條件，並自動出第一組 8 題、產生面試建議。
3. 目標職缺頁可以：
   - 看準備進度（題庫幾題、建議完成多少、最近一次報告幾分）。
   - **編輯原文**：只存文字，不會自動重新出題。畫面會提示「題庫還是依舊內容」，想更新就按「**依新內容重新出題**」。重新出題會換掉 Ava 出的題目，自己加的題目保留。
   - 加上或修改職缺網址。
   - 移出目標職缺（題庫、建議、報告都保留，重新加入就找回）。

## 怎麼測試

**功能**
- 貼一份真實職缺 → 1 分鐘內出現 8 題，公司、職稱、工作內容、條件整理正確。
- 內容少於 20 字 → 不能加入。
- 編輯原文存檔 → 題目完全沒變，出現「原始職缺內容已修改」提示。
- 按「依新內容重新出題」→ 職稱等資訊更新、Ava 的舊題目換成新的、自己加的題目還在、題號連續。出題中再按一次 → 被擋下。
- 職缺網址只接受 http(s)；填了之後出現「前往原始職缺頁」。

**效果**
- 題目有沒有扣住這個職缺：拿兩份差很多的職缺（例如前端 vs 資料工程），題目應該明顯不同，並提到職缺裡的技術或職責。
- 整理出的條件有沒有漏掉原文的重點。
